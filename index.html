소상공인을 위한 AI 스킬 모음

오픈소스 스킬 모음 k-skill에서 소상공인 업무에 쓸 만한 스킬만 골랐습니다. 안내 보기로 스킬이 하는 일을 확인하고, 원본 보기에서 원본 설명과 설치 방법을 확인하세요.

사용 전 꼭 확인하세요

  • 이 스킬들은 Claude Code·Codex 같은 코딩 에이전트에서 쓰는 방식입니다. 일반 Claude 채팅 화면에서는 바로 작동하지 않을 수 있습니다.
  • 스킬을 실행할 때마다 실제 안내문을 npm 패키지(@nomadamas/k-skill)에서 받아오므로 Node.js 18 이상이 설치돼 있어야 합니다.
  • 공공데이터 조회 스킬 상당수는 제작자가 운영하는 중계 서버(k-skill-proxy.nomadamas.org)를 거칩니다. 사업자등록번호 등 조회 내용이 이 서버를 지나가므로 민감한 정보는 넣지 마세요. 서버 상태에 따라 조회가 안 될 수 있습니다.
  • 전체 설치: npx --yes skills add NomaDamas/k-skill --all -g → 설치 후 k-skill-setup 스킬로 공통 설정을 진행합니다.
  • 개인이 공개한 오픈소스이므로, 업무용 PC에 설치하기 전 소속 기관의 보안 검토를 받으세요. 일부 스킬은 외부 API 키가 필요합니다.
  • 장부·세무 결과물은 참고용 초안이며 세무신고나 회계감사를 대체하지 않습니다.
